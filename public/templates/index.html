Animated card templates

Profile README cards built with the bloub engine: a 3D cloud that codes, goes to bed and sings when Spotify is offline. Every card is a single SVG that animates inside a plain <img>, dark and light. Download one, or clone the repo and make your own with the generators in studio/.

The cards

360 × 130, transparent background, colours cycle through 30 palettes every 150 s.

studio/hello.ts: the smallest complete use of the engine, a still frame and a looping animation.

Make your own

git clone https://github.com/blackscythe123/bloub
cd bloub
pnpm install                       # or npm install
npx tsx studio/hello.ts            # output/hello-*.svg
npx tsx studio/bloub-cards.ts      # output/coding|sleeping|spotify-offline-*.svg

Read AGENTS.md for the whole engine API, the SVG recipes and the design rules. Use a card on GitHub with a <picture> so it follows the reader's light or dark theme.
